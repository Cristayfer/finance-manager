# SISTEMA FINANCEIRO

Um projeto simples de controle financeiro desenvolvido em python e sqlite.

## 📳 Tecnologias

- SQLITE3
- PYTHON

## 📌 Funcionalidades Atuais

- Cadastrar movimentações
- Registrar entradas e despesas
- Consultar descrições e valores
- Armazenar dados em banco SQLite
- Visualizar movimentações cadastradas
- Calcular total de entradas e total de despesas
- Calcular saldo total
- Excluir movimentações
- Editar movimentações
- Adicionar data as movimentações
- Filtrar movimentações
- Interface moderna
- Exportação em excel
- Criar categorias

## 📅 Próximas implementações

- Possível versão web
- Aba com resumo de movimentações detalhada
- Ajuda para organização de gastos
